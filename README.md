# 🐱🐶 Cat vs Dog Image Classifier

A beginner-level image classification project created using Google Teachable Machine.

## 📌 Project Overview

The model was trained to classify images into two classes:

- 🐱 Cat
- 🐶 Dog

Approximately 20 images were used for each class.

## 🛠️ Tool Used

- Google Teachable Machine
- Image Classification

## 🔄 Workflow

Dataset → Training → Testing → Prediction

## 📊 Dataset

- Classes: 2
- Cat images: ~20
- Dog images: ~20

This is a small experimental dataset created for learning purposes.

## 🔗 Model
https://teachablemachine.withgoogle.com/models/3mhvJpJNM/

## ⚠️ Limitation

The model was trained using a relatively small dataset, so it should be considered a learning/experimental project rather than a production-ready classifier.
